# Gina on the Road

Interactive travel map for the Gina for Texas campaign: every leg between stops on the scheduling calendar since November 2025, with total miles, hours in transit, travel days and nights away.

Live site: https://texasmaps.github.io/gina-on-the-road/

`index.html` is self-contained (county shapes and route data are embedded). It loads D3 from cdnjs and the Archivo typeface from Google Fonts. To update, replace `index.html` with a freshly built page from `G4T/Calendar/Travel Map/`.
